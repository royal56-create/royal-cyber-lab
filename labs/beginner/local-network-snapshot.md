# Lab 02 — Local Network Snapshot

**Level:** Beginner  
**Target:** Your own machine only  
**Impact:** Read-only inspection; no packets are sent to third-party targets.

## Commands
```bash
ip address
ip route
ss -lnt
```

## Tasks
1. Identify your active interface.
2. Note the local address and route.
3. List listening TCP sockets.
4. For each listening service, identify whether you recognize its owner and purpose.

## Safety
Do not publish public IPs, internal topology, or service details. Do not expand this exercise into scanning networks you do not own or administer.
