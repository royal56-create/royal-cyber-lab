# Security Policy

## Scope
This repository is an educational cybersecurity lab. It is not an authorization to test systems, accounts, networks, or devices belonging to others.

## Reporting
Do not publish exploit details, credentials, personal data, or weaponized proof-of-concept code in an issue. For a suspected vulnerability in this repository, open a minimal report that describes the affected file and safe reproduction context without including secrets.

## Safe handling
- Use only systems you own or have explicit written permission to assess.
- Keep practice targets isolated and disposable.
- Do not upload real logs containing usernames, IP addresses, tokens, or other personal information.
- Stop immediately if an exercise reaches an unintended system.
## User responsibility and warranty notice

Use this project only for lawful learning and on resources you own or are explicitly authorized to use. Review all code and commands before running them, keep independent backups, and protect private data. Use is at your own risk. The project is supplied “as is” without warranties, to the maximum extent permitted by applicable law. Nothing here excludes non-waivable rights, liabilities, or obligations. An educational-purpose notice is not permission to access or test third-party systems.
