# Lab Rules and Learning Path

## Non-negotiable scope
- Target must be localhost, your own isolated VM, or a training target whose rules authorize the activity.
- Use synthetic data.
- No stealth, persistence, credential theft, malware, destructive payloads, or denial-of-service.
- If the target or scope is unclear, do not run the exercise.

## Suggested progression
1. Linux and terminal basics.
2. Files, users, permissions, and processes.
3. Network concepts and local inspection.
4. Log review and defensive monitoring.
5. System hardening and incident-response notes.

Record the goal, commands, expected result, actual result, and cleanup for each lab.
