# Learning Roadmap

## Stage 1 — Foundations
Learn terminal navigation, files, users, permissions, processes, and package management.

**Checkpoint:** explain the output of `whoami`, `uname -a`, `df -h`, and `ss -lnt`.

## Stage 2 — Networking
Understand IP addressing, routes, DNS, TCP/UDP, ports, and sockets.

**Checkpoint:** describe your own machine's active interface and default route without publishing sensitive details.

## Stage 3 — Defensive operations
Learn log formats, event timelines, backups, patching, and least privilege.

**Checkpoint:** analyze the fictional log sample and explain why a single failed login is not proof of compromise.

## Stage 4 — Safe lab practice
Use an isolated VM, synthetic targets, written scope, and a cleanup plan.

**Checkpoint:** write a short report with scope, method, observations, limitations, and remediation.

## Stage 5 — Review
Revisit the safety notice and complete the hardening checklist for a system you administer.
