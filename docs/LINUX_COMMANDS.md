# Linux Command Reference

These are basic, mostly read-only commands. Output can vary by distribution.

| Goal | Command |
|---|---|
| Current directory | `pwd` |
| List files | `ls -lah` |
| Current user | `whoami` |
| System/kernel info | `uname -a` |
| Disk space | `df -h` |
| Memory summary | `free -h` |
| Running processes | `ps aux` |
| IP configuration | `ip address` |
| Routes | `ip route` |
| Listening sockets | `ss -lntup` |
| Manual page | `man COMMAND` |

Before using commands that delete files, change permissions, modify firewall rules, or stop services, understand the impact and use a disposable lab.
