# Defensive Security Basics

A practical defensive workflow:

1. Maintain an inventory of devices, accounts, and exposed services.
2. Apply security updates from trusted repositories.
3. Remove or disable services that are not needed, after checking dependencies.
4. Use unique passwords and multifactor authentication.
5. Apply least privilege; avoid routine work as root.
6. Review authentication and system logs for unusual patterns.
7. Back up important data and test restoration.
8. Document changes and retain a rollback plan.

Prefer detection, hardening, recovery, and verified configuration over intrusive testing.
