# Kali Linux Setup Notes

1. Download Kali only from the official Kali website.
2. Verify the checksum/signature using the official verification guide.
3. Install in a VM for learning; take a clean snapshot.
4. Start with NAT or host-only networking. Avoid exposing lab services to the public internet.
5. Create a non-administrator learner account where practical.
6. Keep host and guest shared folders limited to what is necessary.
7. Do not install random scripts or copy commands from untrusted sources.

This guide intentionally avoids third-party download mirrors and unverified installation commands. Consult the official Kali documentation for current installation and upgrade steps.
