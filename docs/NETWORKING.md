# Networking Fundamentals

Learn these concepts before using assessment tools:

- **IP address:** identifies a network interface within an addressing scheme.
- **Subnet and prefix:** describe the size and boundaries of an IP network.
- **Gateway:** forwards traffic beyond the local network.
- **DNS:** resolves names to records such as IP addresses.
- **TCP/UDP:** transport protocols with different delivery characteristics.
- **Port:** identifies an application endpoint on a host.
- **Socket:** an endpoint used by a process for network communication.

## Safe local observations
```bash
ip address
ip route
ss -lnt
```

These commands inspect the local machine. Do not scan public or third-party address ranges without explicit authorization.
