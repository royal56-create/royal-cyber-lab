# Getting Started

## What you need
- A supported Linux installation or Kali Linux VM.
- A standard user account.
- A terminal and Python 3.10+ for the optional sample-log exercise.
- A snapshot or backup before experimenting with VM settings.

## Recommended setup
1. Install Kali from its official source and verify the download using the publisher's instructions.
2. Prefer a virtual machine with NAT or host-only networking; do not bridge a practice VM to networks you do not administer.
3. Update packages using the normal package manager after reviewing the changes.
4. Clone this repository and read [Legal and Safety](LEGAL_AND_SAFETY.md).
5. Start with the beginner labs. Do not skip the scope and cleanup sections.

## Clone
```bash
git clone https://github.com/royal56-create/royal-cyber-lab.git
cd royal-cyber-lab
python3 tests/check_project.py
```

All scripts in this repository are intended to be read-only demonstrations. Review each file before execution.
