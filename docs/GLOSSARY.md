# Cybersecurity Glossary

- **Asset:** a device, account, application, or data set that has value.
- **Authentication:** verifying a claimed identity.
- **Authorization:** deciding what an authenticated identity may do.
- **CIA triad:** confidentiality, integrity, and availability.
- **CVE:** a publicly catalogued cybersecurity vulnerability identifier.
- **Least privilege:** granting only the access needed for a task.
- **Log:** a recorded event from a system or application.
- **Patch:** an update that fixes defects or security issues.
- **Reconnaissance:** collecting information about a target; only perform it within an explicitly authorized scope.
- **Threat:** a circumstance or actor that could cause harm.
- **Vulnerability:** a weakness that could be exploited.
- **Hash:** a fixed-length digest used to help verify data integrity; it is not encryption.
